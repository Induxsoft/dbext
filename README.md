# Dbext (Utilidades generales).
El paquete Dbext (Utilidades generales) de V12 es el módulo que reúne un conjunto de bibliotecas y aplicaciones de utilidad general diseñadas para simplificar y optimizar el desarrollo y la operación del sistema. Su propósito es proporcionar herramientas transversales que soporten la administración de variables, privilegios, flujos de autorización y servicios básicos que otros módulos del ERP utilizan como base.
